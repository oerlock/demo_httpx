# demo_httpx

Practical examples of using [HTTPX](https://www.python-httpx.org/) in Python.

This repository demonstrates HTTPX usage through small, focused examples, starting with event hooks and expanding to other features and use cases over time.

## Examples

- **Event Hooks** — Explore HTTPX event hooks and their practical applications.

More examples will be added as the project evolves.

## Project Structure

```text
demo_httpx/
├── docs/          # Documentation and development standards
├── examples/      # HTTPX examples organized by feature
├── tests/         # Tests
├── AGENTS.md      # Repository-level instructions
└── README.md
```

## Getting Started

### Requirements

- Python 3.10+
- [uv](https://docs.astral.sh/uv/)
- [HTTPX](https://www.python-httpx.org/)

### Installation

Clone the repository:

```bash
git clone https://github.com/<your-username>/demo_httpx.git
cd demo_httpx
```

Install dependencies:

```bash
uv sync
```

### Run an Example

Navigate to the relevant example directory and follow its instructions.
